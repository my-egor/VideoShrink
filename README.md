# VideoShrink 1.1.6

Настольная программа для пакетной обработки MP4 на Windows 10/11 x64. Очередь обрабатывается последовательно, оригиналы не изменяются. При запуске программа только показывает найденные файлы; обработка начинается после нажатия **«Начать обработку»**.

## Режимы

- **1. Максимальное сжатие без потери качества** — перекодирует поддерживаемое видео в H.265 lossless с preset `medium`, копирует аудиодорожки и принимает результат только если он меньше оригинала, а хеши всех декодированных кадров полностью совпали. К лимиту 2 ГБ этот режим не привязан. Если файл не станет меньше, незавершённый результат удаляется, исходник остаётся нетронутым.
- **2. Усиленное сжатие до лимита** — сначала пробует lossless-кодирование. Если результат не уменьшает оригинал либо не помещается под лимит, программа подбирает CRF на коротких фрагментах и кодирует H.265 с preset `fast`. Для исходников меньше лимита поисковая цель ограничивается 99% размера оригинала; для исходников от 2 ГБ по умолчанию цель — 1,9 ГБ. В любом случае опубликованный результат должен быть меньше исходника, а для больших входов — строго меньше лимита.

Режим 2 может снизить качество. Предупреждение показывается при выборе режима; выбор в главном окне и настройках синхронизирован. После полного кодирования программа проверяет декодируемость, длительность, разрешение, аудиодорожки и полный VMAF. Значение VMAF ниже заданного порога, но подходящий по размеру файл может быть сохранён с явным сообщением о недостигнутом пороге. Порог по умолчанию — 95.

Размер lossless-результата не гарантирован: некоторые MP4 уже сжаты лучше, чем H.265 lossless. При отказе из-за размера программа сохраняет оригинал и не публикует частичные файлы. Видео с HDR, BT.2020, глубиной более 8 бит, дополнительными видеодорожками, субтитрами, вложениями или другими неподдержанными потоками отклоняются, чтобы не потерять свойства и дорожки.

## Работа с portable-версией

1. Распакуйте `VideoShrink_Portable_1.1.6.zip` в удобную папку.
2. Поместите MP4 в `Input`.
3. Запустите `VideoShrink.exe`, выберите режим и нажмите **«Начать обработку»**.
4. Готовые файлы появятся в `Output`, отчёт и журнал — в `Logs`.

Portable-сборка включает Python-приложение и FFmpeg/FFprobe; на другом компьютере отдельно устанавливать Python или FFmpeg не требуется. Временные данные, настройки и история находятся в папке portable-сборки. Не перемещайте её, пока программа работает.

## Интерфейс и диагностика

Полоса показывает процент завершения. Заполненная зелёная часть движется, даже если FFmpeg не сообщает новый процент; рядом видны текущий этап, прошедшее время и оценка оставшегося времени. Прогноз обновляется по фактической скорости кодирования и может измениться после перехода к усиленному сжатию.

Журнал `Logs/app.log` содержит длительность этапов, режим, выбранные параметры кодирования, размеры кандидатов, VMAF и причины отказа. Содержимое видео в журнал не записывается. `Logs/last_report.json` содержит итог по очереди.

## Запуск из исходников

Нужен Python 3.12 x64 и совместимые `ffmpeg.exe`/`ffprobe.exe` в `tools/`. Запуск: `python run.py`. В portable-версии данные хранятся рядом с EXE; установленная версия использует пользовательскую папку Windows «Видео».

## Проверки и сборка

Запуск тестов: `python -m unittest discover -s tests -v`.

Сборка выпуска: подготовьте FFmpeg и NSIS закреплённых версий командами `./prepare_ffmpeg.ps1` и `./prepare_nsis.ps1`, затем выполните `./build.ps1`. Скрипт формирует onedir, Portable ZIP и NSIS-установщик, сверяя SHA-256 сборочных компонентов. Исходник Inno Setup `installer.iss` также сохранён, но сборка по умолчанию использует NSIS.

Сравнение полного контрольного ролика и ограничения замеров приведены в [отчёте об оптимизации качества и размера](docs/performance/video-quality-size-policy.md).
